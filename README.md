# Bridges Learning Studio

A self-contained education demo with a splash screen, an activity library, student registration, scorecards, and a playable color-matching assessment.

## Run

Open `index.html` in a modern browser. All styles, application code, logo assets, the sample Excel workbook, and the Excel reader are included in that file.

## Deploy on Netlify

Connect this repository, select the `main` branch, leave the build command empty, and set the publish directory to `.`.

## Demo scope

AI chat, account creation, and sending activities to student groups are simulated. Imported students and activity results remain in memory and reset when the page reloads. This demo has no backend or authentication.
